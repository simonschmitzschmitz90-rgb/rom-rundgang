# Römische Schnitzeljagd – Website

## Inhalt
- `index.html` = Startseite mit allen Stationen
- einzelne HTML-Seiten für jede Station
- `rom-models.js` = stilisierte 3D-Modelle im Browser
- `styles.css` = gemeinsames Design

## Stationen
1. Kolosseum
2. Curia Julia
3. Forum Romanum
4. Triumphbogen
5. Wohnhaus der einfachen Bevölkerung
6. Aquädukt
7. Trajansthermen
8. Palatin mit Palastanlage
9. Circus Maximus

## So setzt du es ein
1. ZIP entpacken
2. Ordner auf GitHub Pages, Netlify oder einen Schulserver hochladen
3. Für jede Stationsseite einen QR-Code erzeugen:
   - `kolosseum.html`
   - `curia-julia.html`
   - `forum-romanum.html`
   - `triumphbogen.html`
   - `wohnhaus.html`
   - `aquaedukt.html`
   - `trajansthermen.html`
   - `palatin.html`
   - `circus-maximus.html`

## Hinweis zu AR
Die Website enthält direkt nutzbare 3D-Browsermodelle.
Wenn du echtes AR auf iPads möchtest, ergänze pro Station zusätzlich GLB/USDZ-Dateien
und tausche den Browser-Viewer später gegen `<model-viewer>` oder Apple Quick Look aus.
